## 2. Постановка задачи

---

## 3. Описание реализации

### Архитектура программы

Программа состоит из класса TaskQueue (потокобезопасная очередь задач, рабочих потоков worker (получают и обрабатывают задачи),главного потока main (создаёт потоки, добавляет задачи и ожидает завершения работы).

---

### Реализация потокобезопасной очереди

Для хранения задач используется контейнер std::queue<int>.

Для защиты очереди от одновременного доступа нескольких потоков используется std::mutex.

При добавлении и извлечении задач выполняется блокировка mutex.

---

### Использование `condition_variable`

std::condition_variable используется для ожидания появления новых задач.

Если очередь пуста, рабочий поток переходит в состояние ожидания: cv.wait(lock).

После добавления новой задачи, чтобы избежать busy-wait и не расходовать процессорное время, главный поток вызывает cv.notify_one().

---

### Механизм корректного завершения потоков

После обработки всех обычных задач главный поток добавляет в очередь специальные значения -1.

Количество таких значений соответствует количеству рабочих потоков.

Если поток получает задачу со значением -1, он завершает свою работу и выходит из цикла обработки задач.

После завершения всех потоков главный поток ожидает их завершения с помощью метода join().
